# Konsol

Дешевий USB-джойстик (PC/PS3/Android) на ПК часто видно як DirectInput, а ігри чекають Xbox. Konsol читає твій пад і піднімає віртуальний **Xbox 360** або **DualShock 4**. Є режим **клавіатура + миша** для ігор без геймпада.

Репозиторій: https://github.com/mishashish/konsol

---

## Як користуватися (коротко)

1. Підключи джойстик по USB.
2. Запусти **Konsol** (ярлик на робочому столі або з меню Пуск).
3. На головній вибери режим:
   - **Xbox 360** — майже всі ігри (Fortnite, Steam тощо)
   - **PlayStation 4** — якщо хочеш підказки з кнопками PS
   - **Клавіатура і миша** — ігри без підтримки геймпада
4. Потикай кнопки на джойстику — вони мають світитися на схемі в вікні.
5. Заходь у гру і натисни будь-яку кнопку на паді.

Хрестик вікна **не закриває** програму — згортає в трей (біля годинника). Геймпад далі працює. Повний вихід: ПКМ по значку в треї → «Вихід».

## Що запускати і де воно лежить

| Що | Де |
|---|---|
| Встановлена програма | `%LOCALAPPDATA%\Programs\Konsol\Konsol.exe` |
| Ярлик | Робочий стіл / Пуск → **Konsol** |
| Налаштування | `%APPDATA%\Konsol\` |
| Збірка з коду | папка проєкту → `build.bat` → з’явиться `dist\Konsol.exe` |

### Якщо exe вже зібраний

1. Запусти `dist\Konsol.exe` **один раз**.
2. Він сам поставить себе в `%LOCALAPPDATA%\Programs\Konsol`, зробить ярлики і увімкне автозапуск.
3. Далі користуйся ярликом з робочого столу.

### Якщо ставиш з нуля (з коду)

```bat
pip install -r requirements.txt
build.bat
```

Потім запусти `dist\Konsol.exe` один раз (як вище).

Або без збірки, для розробки:

```bat
python app.py
```

## Налаштування в програмі

**Головна** — статус, вибір режиму, перевірка кнопок на схемі.

**Розкладка** — якщо кнопки переплутані:
- «Почати налаштування» — по черзі підсвічує кнопку, ти натискаєш її на джойстику
- або «Змінити» біля однієї кнопки

**Клавіші** — тільки для режиму «Клавіатура і миша»: що натискатиметься в грі (WASD, ЛКМ тощо).

**Steam** — увімкни «Режим для Steam», щоб Steam не бачив «сирий» джойстик паралельно з віртуальним (менше подвійних натискань). Якщо Steam уже відкритий — натисни «Перезапустити Steam».

**Налаштування** — мертва зона стіків, вібрація, автозапуск, перевірка через Windows (`joy.cpl`), видалення Konsol.

## Якщо щось не працює

- **Стіки не рухаються** — на джойстику кнопка **ANALOG / MODE** (часто червоний діод).
- **Немає драйвера** — на головній буде кнопка «Встановити драйвер» (ViGEmBus).
- **У грі не керується** — режим **Xbox 360**, Konsol у треї, у Fortnite просто натисни кнопку на паді.
- **Персонаж сам повзе** — у «Налаштуваннях» мертва зона стіків 8–12%.
- **Steam** — Steam → Налаштування → Контролер: «Підтримка звичайних геймпадів» вимкни; для однієї гри можна погратися зі Steam Input у властивостях гри.

## Залежності

- pygame — читання джойстика  
- vgamepad + ViGEmBus — віртуальний геймпад  
- customtkinter, pystray, pillow — вікно і трей  

Тести: `pytest -q tests`

## Примітка

На справжню консоль PS4/Xbox цей китайський пад прошивкою не зробити — там потрібна сертифікація. Тут лише емуляція для Windows.
